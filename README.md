# Gestor Financiero CLI 📊

Una sencilla aplicación por terminal (CLI) desarrollada en **Python** para gestionar transacciones financieras personales. Permite registrar movimientos, calcular balances en tiempo real y persistir los datos de forma segura en el disco duro.

---

## Características Principales✨
* **Registro de Transacciones:** Añade ingresos y gastos de forma rápida desde la terminal.
* **Cálculo de Balance:** Obtén el balance total acumulado en base a las operaciones registradas.
* **Persistencia en Disco:** Guarda y lee los datos automáticamente en formato **JSON** para no perder la información al cerrar la aplicación.

## Tecnologías Utilizadas 🛠️
* **Lenguaje:** Python 3.x
* **Almacenamiento:** Archivos JSON (Módulo nativo `json`)

## Instalación y Uso  🚀

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/brandonvht26/cli-gestor-financiero.git
   cd cli-gestor-financiero
   ```

2. **Ejecuta la aplicación:**
   ```bash
   python main.py
   ```
